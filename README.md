## 🚀 Mahalliy Ishga Tushirish (Local Setup)

Loyiha toza HTML5, Vanilla JavaScript va zamonaviy CSS texnologiyalarida yaratilgan bo'lib, qo'shimcha og'ir kutubxonalarsiz ishlaydi:

1. Repozitoriyni klonlash:
   ```bash
   git clone https://github.com/Hikki1987/tajriba24.git
   cd tajriba24
   ```
2. Brauzerda ochish:
   - `index.html` faylini ikki marta bosing, yoki:
   ```bash
   npx serve .
   ```
